## Training input policy

The repository intentionally contains NO raw CMEMS/ADT NetCDF or NetCDF file inventories. Original sources are available separately from CMEMS. Only derived datasets are distributed.

Known original CMEMS historical directory: `GLOBAL_MULTIYEAR_PHY_001_030 / cmems_mod_glo_phy_myint_0.083deg_P1D-m / YYYY`. Newer supplementary daily data may be in an `E:/YYYY` structure.

Original NetCDF deliberately not scanned. Excluded/review items: **2**; see the machine-readable manifest. Oversize derived training files may be stored as checksummed parts requiring restoration. No intermediate R1–R64 experimental checkpoints or repeated optimization result datasets were intentionally included.

## Attribution / interpretation

The final dual-branch dataset is constructed from CMEMS GLORYS daily 50-m velocity-derived Kuroshio axes. ADT-derived reference axes are a distinct observational product used for cross-product consistency validation; they are not a direct substitute for independent in-situ truth. Display filtering of paths is not a model accuracy improvement. Research histograms and forecasts must be interpreted within their respective evaluation contracts.

## Privacy, storage & provenance

- Never commit API keys, SSH credentials, personal VPN configs, local `.env` files or secret-bearing notebooks.
- GitHub ordinary Git has 100 MiB per-file hard limit; large research binaries require Git LFS and sufficient storage/bandwidth quota.
- Original source NetCDF files are absent by design; no F:/E: mount is needed for publishing.
- SHA256 hashes refer only to files actually included. Other original files remain at their local WSL source location.
- Do not present the `human corrected days` total as all human-reviewed samples; manual review without path correction is counted separately in metadata.
